# Практическая работа № 3 — панель учебного проекта

## Запуск

Распакуйте ZIP целиком и откройте `index.html` в браузере с доступом к интернету. Bootstrap 5.3.8 загружается с официального CDN, а собственные CSS, JavaScript и SVG находятся в папках проекта. Установка пакетов или сборка не требуются.

## Что реализовано

- Адаптивный navbar с мобильным раскрытием.
- Четыре карточки показателей из `data/dashboard.json`.
- Таблица восьми записей из того же JSON и фильтр по статусу.
- Bootstrap modal с формой добавления операции и проверкой названия (3–60 символов).
- Bootstrap offcanvas с краткой справкой о данных проекта.
- Bootstrap collapse для подсказки над таблицей.
- Bootstrap toast с сообщениями из `data/notifications.json`.
- Адаптивная таблица и пользовательские детали в `css/custom.css`.

## Файлы

- `index.html` — разметка панели, показатели, таблица и Bootstrap-компоненты.
- `js/app.js` — фильтрация строк, проверка формы, добавление записи, обновление счётчика, программное управление modal и toast.
- `css/custom.css` — цвета, карточки показателей, статусы и небольшие собственные стили поверх Bootstrap.
- `data/dashboard.json` — четыре исходных метрики и восемь исходных операций.
- `data/notifications.json` — исходные уведомления об успехе и предупреждении.
- `images/avatar.svg`, `images/chart.svg` — изображения из dataset.
- `.gitignore` — исключения для локальных временных файлов.

## Данные и обработчики

Значения в метриках и таблице перенесены из `dashboard.json` без изменения. Тексты двух toast берутся из `notifications.json` и повторены в объекте `notifications` в `js/app.js`, чтобы демонстрация работала при открытии `index.html` напрямую, без локального сервера и запроса `fetch` к JSON. Новые записи добавляются только в текущий DOM и не сохраняются после перезагрузки страницы.

В `app.js` есть отдельные обработчики для изменения фильтра, ввода и отправки формы, закрытия modal и нажатия кнопки уведомлений. Для успешного сохранения вызываются `bootstrap.Modal.getOrCreateInstance(...).hide()` и `bootstrap.Toast.getOrCreateInstance(...).show()`; это программное управление компонентами Bootstrap.

## Bootstrap JavaScript и собственный JavaScript

Bootstrap CSS задаёт сетку, кнопки, формы и базовый вид компонентов. Bootstrap JavaScript обрабатывает `navbar collapse`, modal, offcanvas, collapse и toast. Код `js/app.js` отвечает за данные панели, фильтр статусов, валидацию пользовательского ввода, добавление новой строки и выбор сообщения для toast. Bootstrap JS не заменяет эту логику приложения.

## Проверка вручную

1. Откройте страницу на ширине около 1440 px и проверьте четыре метрики и восемь строк.
2. Выберите разные значения фильтра статуса; счётчик должен показывать число видимых строк.
3. На ширине 375 px раскройте navbar, откройте modal, offcanvas и подсказку.
4. В modal попробуйте пустое название или текст короче трёх символов: появится `is-invalid` и предупреждение из dataset. Затем введите корректное название, сохраните и проверьте новую строку и toast успеха.
5. Откройте DevTools Console и убедитесь, что Bootstrap загружен и ошибок нет.

## Ответы на контрольные вопросы

1. Приложение основано на `data/dashboard.json`, `data/notifications.json` и SVG из `images/`.
2. Исходные метрики и строки уже размечены в `index.html`, а `js/app.js` фильтрует таблицу и добавляет новую запись в DOM.
3. Вручную проверяется некорректное имя операции: пустое значение и длина менее трёх символов. Ошибочному полю назначается `is-invalid`, toast показывает предупреждение. Корректное поле получает `is-valid`.
4. При увеличении проекта данные нужно загружать через API, разделить интерфейс на компоненты, вынести проверки и форматирование в модули и хранить созданные записи на сервере.
5. После чистого клонирования распакуйте репозиторий и откройте `index.html`; для интерактивных компонентов нужен интернет, чтобы загрузить Bootstrap CDN. Затем пройдите ручной сценарий выше.
6. HTML-элементы дают содержимому структуру и смысл, CSS отвечает за оформление и компоновку. Bootstrap-классы — готовые стили, а семантические теги и подписи остаются в HTML.
7. Собственный браузерный JavaScript реализует логику именно этой панели; Bootstrap JavaScript управляет интерактивностью готовых Bootstrap-компонентов. В проекте используются оба слоя.
